ограничения - при выборе столбцов в каждом из запросов SELECT количество столбцов должно совпадать;
- типы данных каждого из столбцов должны быть совместимыми;
- порядок столбцов в каждом из запросов SELECT должны быть одинаковыми.

Кроме того, если нам необходимо упорядочить результаты выборки, то ORDER BY должен находиться в конце последнего запроса. Мы не можем добавить ORDER BY в каждый запрос SELECT перед оператором множества.

Оператор множества UNION позволяет объединить результаты двух запросов. Этот оператор удаляет все повторяющиеся строки и показывает нам комбинацию обоих результатов выборок SELECT.Т.е. в результате выборки мы получим все результаты из обоих SELECT при этом пересекающиеся данные (дубликаты) в результатах будут отражены в единственном количестве.

Оператор множества UNION ALL также объединяет результаты двух и более запросов. Однако в отличие от UNION, он не удаляет дубликаты.

Оператор EXCEPT - вернет результаты, которые присутствуют в результатах первого запроса, исключая тех результатов, которые присутствуют во втором запросе
SELECT first_name, last_name
FROM customers
EXCEPT
SELECT first_name, last_name
FROM employees;

Оператор множества INTERSECT используется для того, чтобы получить результаты, которые существуют в результатах выборки обоих запросов.
SELECT first_name, last_name
FROM customers
INTERSECT
SELECT first_name, last_name
FROM employees;


Важно! Операторы UNION и EXCEPT обрабатываются одинаково и выполняются по порядку в запросе от начала и до конца, но если в запросе присутствует оператор INTERSECT, то он имеет приоритет над другими операторами, то есть будет выполняться первым.

**Подведем итоги:**

1. При использовании операторов множеств количество столбцов в каждом из запросов SELECT должно быть одинаковым. При этом в качестве имен столбцов будут выбраны те, которые указаны для них в первом из запросов SELECT;

2. Типы данных списка столбцов должны быть совместимы или же способны быть неявно преобразованы СУБД;

3. Для того, чтобы выполнить сортировку результатов выполнения запроса можно использовать ORDER BY. Он должен быть самым последним оператором в запросе;

4. Порядок запросов в UNION и INTERSECT не важен, от перестановки запросов окончательный результат не изменится;

5. UNION ALL необходимо использовать в том случае, что результаты выборки не имеют дубликатов;

6. UNION ALL работает быстрее, чем UNION, поскольку UNION тратит дополнительные накладные расходы на устранение дубликатов;

7. Объединять можно 3 и более запросов с помощью операторов множества. Для того чтобы определить порядок объединения и, соответственно выполнения запросов, используются круглые скобки.

Стоит подчеркнуть, что для разных СУБД эта таблица может иметь различный вид.  Все зависит от реализации уровней изолированности транзакций в той или иной СУБД.

|                                                                               |                       |                |                        |                  |
| ----------------------------------------------------------------------------- | --------------------- | -------------- | ---------------------- | ---------------- |
| ----------------------                                                        | Потерянное обновление | Грязное чтение | Неповторяющееся чтение | Фантомное чтение |
| Чтение неподтвержденных данных, грязное чтение (read uncommitted, dirty read) | Защищает              | Не защищает    | Не защищает            | Не защищает      |
| Чтение подтвержденных данных                                                  | Защищает              | Защищает       | Не защищает            | Не защищает      |
| Повторяющееся чтение                                                          | Защищает              | Защищает       | Защищает               | В PG защищает    |
| Снимок                                                                        | Защищает              | Защищает       | Защищает               | Не защищает      |
| Сериализация                                                                  | Защищает              | Защищает       | Защищает               | Защищает         |
**Чтение неподтвержденных данных, грязное чтение (read uncommitted, dirty read)** – данный уровень изолированности позволяет читать незафиксированные изменения (до подтверждения или отмены транзакции) выполненных любой транзакцией (как той, что читает данные, так работающая параллельно с ней).

SET SESSION TRANSACTION ISOLATION LEVEL READ UNCOMMITTED;
параллельная транзакция видит несохраненные данные внутри другой транзакции. Со всеми вытекающими последствиями

**Чтение подтвержденных данных (read committed)** – данный уровень изолированности транзакций допускает чтение всех изменений, которые выполнены транзакцией, и только зафиксированных изменений, выполненных другими параллельными транзакциями.


**Повторяющееся чтение (repeatable read)** – этот уровень изолированности допускает только чтение изменений, которые выполнены самой транзакцией, а прочитанные ею данные будут недоступны для изменения параллельными транзакциями.

Данный уровень обеспечивает отсутствие потерянных обновлений, грязного чтения и неповторяющегося чтения, однако допускает фантомное чтение.

Физически этот уровень изолированности транзакций реализуется через блокировку прочитанных данных, что запрещает параллельным транзакциям изменять строки таблиц. Однако, параллельные транзакции могут вставлять новые строки, что может породить проблему фантомного чтения.

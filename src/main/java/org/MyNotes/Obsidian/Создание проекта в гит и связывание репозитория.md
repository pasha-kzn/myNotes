
Откройте сайт github.com - [click](https://github.com/new).
Ввести название проекта
Нажмите кнопку Create repository. Никаких настроек больше не делайте.
После создания репозитория откроется окно с быстрыми настройками, на этой странице нам достаточно скопировать адрес репозитория:
Обязательно требуется переключить закладку ссылки на протокол SSH. Нажимаем кнопку копировать.

Далее нам нужно привязать проект к новому репозиторию.
Все действия мы делаем в терминале IDEA. Он находится внизу окна.

git init

git remote add origin СКОПИРОВАННЫЙ_АДРЕС_ИЗ_3_ПУНКТА_ЭТОГО_УРОКА_ПРИ_СОЗДАНИИ_РЕПОЗИТОРИЯ
пример:
git remote add origin git@github.com:carbonil-ks/job4j_tracker.git

### …or push an existing repository from the command line

git remote add origin git@github.com:pasha-kzn/job4j_grabber.git
git branch -M main
git push -u origin main



Выполните команду для проверки адреса.
git remote -v

Выполните команду для переключения ветки.
git checkout -b master
git fetch
